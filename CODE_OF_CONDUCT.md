# Code of conduct

Be respectful and constructive in issues, pull requests, and discussions.
Critique ideas and code without personal attacks, harassment, or threats.
Do not publish another person's private information.

Maintainers may edit or remove abusive content, close discussions, and block
participants who repeatedly disregard these expectations. Use GitHub's
reporting controls to flag abusive content; contact a maintainer privately
when a public report would expose someone.
