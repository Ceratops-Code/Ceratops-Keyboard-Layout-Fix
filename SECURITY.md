# Security policy

Please report a suspected security vulnerability through
[private vulnerability reporting](https://github.com/Ceratops-Code/Ceratops-Keyboard-Layout-Fix/security/advisories/new).
Include the affected version, steps to reproduce, and the likely impact.
Avoid posting exploit details in a public issue before maintainers can assess
the report.

Security fixes are considered for the current release. Older releases are not
maintained separately.
