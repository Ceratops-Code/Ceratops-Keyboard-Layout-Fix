# Contributing

Please open an issue before a substantial change so its behavior can be
discussed. Pull requests should explain the user-visible change and include
the relevant test result.

Repository validation runs in GitHub Actions. Interactive keyboard and editor
tests require a signed-in Windows desktop and are described in the
[user guide](README.txt). Run the relevant desktop checks before submitting a
change to conversion, shortcuts, or installation. Do not run the global
shortcut test alongside an installed Ceratops tray instance.

Keep the AutoHotkey and UIA-v2 license notices with any redistributed bundle.
